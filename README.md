# Promotora Senderos S.A.S.

Sitio web corporativo de Promotora Senderos S.A.S., constructora colombiana
especializada en gerencia, promoción y construcción de proyectos inmobiliarios,
con énfasis en Vivienda de Interés Social (VIS).

## Contenido

- Inicio corporativo
- Nosotros, misión y visión
- Servicios y actividad principal
- Proyectos
- Enfoque VIS
- Sostenibilidad
- Novedades
- Contacto

## Requisitos

- Node.js 22.13 o superior
- npm o pnpm

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificación para producción

```bash
npm run build
```

El proyecto utiliza Next.js, React y vinext, con estilos corporativos
responsive y recursos gráficos propios de Promotora Senderos.
